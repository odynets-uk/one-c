## Мета

Пришвидшити COM-витяг цін/залишків з регістрів 1С. Поточна швидкість — 281 с на 8 товарів, що робить повний синк непрактичним. Ціль — суттєве зменшення часу витягу (орієнтовно < 30 с на тих самих даних).

## Технічні рішення / Контекст

### Діагноз (з аналізу коду 2026-08-09)

1. **`LoadPrices()` читає ВЕСЬ регістр цін** — вся історія `ЦеныНоменклатуры` вивантажується в пам'ять, відбір останнього запису робиться в .NET. Потрібен `СрезПоследних` прямо в запиті 1С.
2. **COM round-trip на кожен рядок** — `GetRefGuid()` викликає `УникальныйИдентификатор` через `InvokeMember` для кожного посилання в кожному рядку. Один і той же товар/тип ціни зустрічається в багатьох рядках — GUID витягується повторно. Те саме з `GetRefName()` для одиниць виміру.
3. **`BuildStock()` — квадратична складність O(n×m)** — для кожного товару лінійний пошук по всьому списку залишків.
4. **`BuildPrices()`** — лінійний пошук по `priceTypes` для кожного товару.
