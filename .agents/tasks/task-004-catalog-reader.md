## Мета

Реалізувати динамічне вичитування даних з 1С через COM з пакетною обробкою та маппінгом значень.

## Обсяг

- [ ] `OneC.Infrastructure/Readers/ComValueMapper.cs` — маппінг COM-значень → .NET (Ref→GUID, Enum→string, decimal, bool, dateTime)
- [ ] `OneC.Infrastructure/Readers/CatalogReader.cs` — динамічне вичитування: `Выбрать()` + `ВыбратьСледующий()`, пакетна обробка
- [ ] Обробка табличних частин (`CatalogTabularSectionRow.*`)
- [ ] `OneC.Cli` команда `get-catalog <name> --fields a,b,c --limit N` — вивід у JSON
- [ ] Профілювання розміру батча (100/500/1000) — вимірювання часу/пам'яті

## Критерії готовності

- [ ] `get-catalog` вичитує дані з бази 1С і виводить у JSON
- [ ] Маппінг типів коректний (Ref→GUID, Enum→string, decimal, bool, dateTime)
- [ ] Пакетна обробка працює (не завантажує всі дані в пам'ять)
- [ ] Тести маппінгу (unit) проходять
- [ ] Коміт створено з multiline повідомленням

## Технічні рішення / Контекст

- Використовувати `Выбрать()` + `ВыбратьСледующий()` для потокової вибірки
- `ВыбратьПорциями()` якщо підтримується версією 8.3.10
- Маппінг: Ref → GUID string, Enum → string, decimal → decimal, bool → bool, dateTime → DateTime
- Табличні частини — окремі записи або JSON
